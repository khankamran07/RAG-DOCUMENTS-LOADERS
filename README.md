# RAG-DOCUMENTS-LOADERS

## Overview
This project demonstrates how to load and extract
data from different document formats using LangChain.

## Supported Document Loaders
- PyPDFLoader
- PDFPlumberLoader
- PDFMinerLoader
- JSONLoader
- TextLoader
- CSVLoader
- WebBaseLoader

## Installation

Install dependencies:

pip install -r requirements.txt

## Usage

Run the Python files to load and extract
documents from different file formats.

## Technologies Used
- Python
- LangChain
- LangChain Community
- PyPDF
- RapidOCR
